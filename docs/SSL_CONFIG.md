# SSL/TLS Configuration for MySQL

## Overview

The PAMA API now supports SSL/TLS connections to MySQL databases. This allows secure connections with certificate verification.

## Environment Variables

Add these variables to your `.env` file:

### Required Database Settings

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=kampul_user
DB_PASSWORD=your_secure_password_here
DB_NAME=kampul_sis_client_db
```

### Optional SSL Settings

```env
# SSL Certificate paths (optional)
DB_SSL_CA=./ssl_certs/ca.pem
DB_SSL_CERT=./ssl_certs/client-cert.pem
DB_SSL_KEY=./ssl_certs/client-key.pem

# SSL Mode (default: PREFERRED)
DB_SSL_MODE=PREFERRED
```

## SSL Modes

| Mode              | Description                                 |
| ----------------- | ------------------------------------------- |
| `DISABLED`        | No SSL encryption                           |
| `PREFERRED`       | Use SSL if available (default)              |
| `REQUIRED`        | SSL required, but don't verify certificates |
| `VERIFY_CA`       | SSL required, verify CA certificate         |
| `VERIFY_IDENTITY` | SSL required, verify CA and server identity |

## Certificate Files

### ca.pem (CA Certificate)

- **Purpose**: Verifies the server's SSL certificate
- **Required**: Only if using `VERIFY_CA` or `VERIFY_IDENTITY` mode
- **Location**: Usually provided by your database provider

### client-cert.pem (Client Certificate)

- **Purpose**: Client authentication certificate
- **Required**: Only if server requires client certificates
- **Location**: Generated by your database provider

### client-key.pem (Client Private Key)

- **Purpose**: Private key for client certificate
- **Required**: Only if using client certificates
- **Location**: Generated by your database provider

## Usage Examples

### Without SSL (Default)

```env
DB_HOST=your-db-host
DB_PORT=3306
DB_USER=your-user
DB_PASSWORD=your-password
DB_NAME=your-database
# No SSL settings = PREFERRED mode
```

### With ca.pem only

```env
DB_HOST=your-db-host
DB_PORT=3306
DB_USER=your-user
DB_PASSWORD=your-password
DB_NAME=your-database
DB_SSL_CA=./ssl_certs/ca.pem
DB_SSL_MODE=VERIFY_CA
```

### With full SSL certificates

```env
DB_HOST=your-db-host
DB_PORT=3306
DB_USER=your-user
DB_PASSWORD=your-password
DB_NAME=your-database
DB_SSL_CA=./ssl_certs/ca.pem
DB_SSL_CERT=./ssl_certs/client-cert.pem
DB_SSL_KEY=./ssl_certs/client-key.pem
DB_SSL_MODE=VERIFY_IDENTITY
```

## Testing Connection

Run the test script to verify your SSL configuration:

```bash
python test_ssl_connection.py
```

This will show:

- Connection status
- SSL configuration being used
- SSL encryption status
- Available tables

## Troubleshooting

### Common Issues

1. **Certificate file not found**

   - Ensure file paths in `.env` are correct
   - Use absolute paths if relative paths don't work

2. **SSL connection failed**

   - Check if your database server supports SSL
   - Verify SSL mode matches server requirements

3. **Certificate verification failed**
   - Ensure ca.pem matches your database server's CA
   - Check certificate expiration dates

### Aiven Cloud SSL

For Aiven Cloud databases:

- SSL is usually required
- Download ca.pem from your Aiven dashboard
- Set `DB_SSL_MODE=REQUIRED` or `VERIFY_CA`
